# Wallpaper artwork

Lumen ships ten original wallpapers generated with the built-in imagegen tool. Aurora, Dusk, and Glacier were created on 2026-10-03; the seven additions below were created on 2026-10-05. All outputs were inspected and converted to optimized JPEGs at 1672 × 941, matching the existing assets. The generated PNG originals remain in the tool's image directory; the application and both installation paths use the repository assets below.

## Aurora

Asset: `lumen/wallpapers/aurora.jpg`

Final generation prompt:

```text
Use case: stylized-concept
Asset type: built-in widescreen wallpaper behind a framed screen recording in Lumen
Primary request: a premium abstract aurora wallpaper, luminous soft flowing ribbons of emerald and electric teal light over deep midnight blue, subtle violet haze at the edges, beautiful restrained cinematic glow.
Composition/framing: 16:9 landscape, 2048x1152; broad sweeping forms visible around all outer edges, quiet darker center that will be covered by the recording. Full bleed, smooth gradients, refined soft grain, no objects.
Constraints: wallpaper artwork only, no text, no logos, no watermark, no UI, no border.
```
