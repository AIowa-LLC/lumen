# Wallpaper artwork

Lumen ships three original wallpapers generated with the built-in imagegen tool on 2026-10-03. The outputs were inspected and converted to optimized JPEGs at their native 1672 × 941 resolution, without cropping. The generated PNG originals remain in the tool's image directory; the application and both installation paths use the repository assets below.
